Motion Vectors for X-Plane 12 - version @VER@ (developer build)


INSTALL

1. Open your X-Plane 12 folder, the one that contains X-Plane.exe.
2. Drag everything inside this zip into it.
3. Choose Merge, and Replace, if Windows asks.

You should then have:

    X-Plane 12\vulkan-1.dll
    X-Plane 12\vk_real_mv.dll
    X-Plane 12\MotionVectors\VkLayer_mv.dll
    X-Plane 12\MotionVectors\VkLayer_mv.json
    X-Plane 12\MotionVectors\nn_aa.bin
    X-Plane 12\MotionVectors\taa_live.ini
    X-Plane 12\Resources\plugins\MotionVectors\64\win.xpl
    X-Plane 12\Resources\plugins\FlyWithLua\Scripts\MotionVectors.lua


RUN

Start X-Plane the way you always do, from Steam or from X-Plane.exe.
There is no launcher any more.

vulkan-1.dll beside X-Plane.exe is a small shim. Windows loads it instead
of the system Vulkan loader, it forwards every Vulkan call to
vk_real_mv.dll (an unmodified copy of the system loader), and it switches
the Motion Vectors layer on in the MotionVectors folder.


SETTINGS

The mod reads this file, and changes apply in a few frames while the sim
is running:

    %TEMP%\taa_live.ini

The shim does not create it. To use the shipped tuning, copy
MotionVectors\taa_live.ini to %TEMP%\taa_live.ini once. Without the file,
every setting falls back to its built-in default.


TURN IT OFF

In the sim: Plugins menu, FlyWithLua, Motion Vectors.

Or set taa.enable=0 in %TEMP%\taa_live.ini while the sim is running.


UNINSTALL

Delete vulkan-1.dll and vk_real_mv.dll from the X-Plane 12 folder. That
alone returns X-Plane to stock. Then delete the MotionVectors folder, the
Resources\plugins\MotionVectors folder and the MotionVectors.lua script.
Nothing was written to the registry.


REQUIREMENTS

X-Plane 12 running on Vulkan, not OpenGL.
FlyWithLua, for the settings panel only. The mod works without it.


ANTIVIRUS

Some scanners flag vulkan-1.dll because it is a DLL placed beside a game
that replaces a system library. That is exactly what it does, openly: it
forwards the Vulkan API and loads the Motion Vectors layer. No networking,
no registry, no file writes. The source is in the repository.
